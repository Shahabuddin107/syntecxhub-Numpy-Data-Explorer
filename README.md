# NumPy Data Explorer

A hands-on Python project exploring the core capabilities of NumPy.

## Features Covered
- **Array Basics:** Creation, multi-dimensional indexing, slicing.
- **Math & Statistics:** Mean, std deviation, min/max, axis-wise (row/column) calculations.
- **Reshaping & Broadcasting:** Array restructuring and element-wise arithmetic across shapes.
- **I/O:** Saving and loading array data using `.npy` binary format.
- **Benchmark:** Execution speed comparison between Python lists and vectorized NumPy arrays.

## How to Run
```bash
pip install numpy
python numpy_explorer.py
